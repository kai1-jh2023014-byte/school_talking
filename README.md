# つなぐ

高校生テックコンテスト2026 企画の実装です。

生徒が「質問したい」と思った瞬間に、対応できる先生へつなぐ学校内プラットフォームです。

> 先生を探すのではなく、質問が先生を見つける。

## できること

- **生徒**: 学籍番号で入る。文章や写真で質問する。AIが科目・分野・緊急度を整理し、今対応できる先生を案内する
- **先生**: 職員番号で入る。「今質問OK / 少し待てば / 対応不可 / 本日終了」を出す。待ち行列の質問に、対応・保留・転送・回答できる
- **管理者**: 科目別・分野別・時間帯別の質問から、生徒がどこでつまずいているかを見る

AIは答えを書きません。人と人のあいだの壁を外すために使います。

生徒用と先生用のログインは分かれています。生徒の学籍番号では先生画面に入れず、職員番号では生徒画面に入れません。

## 起動

```bash
npm install
npm test
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

- 生徒入口: [/login/student](http://localhost:3000/login/student)
- 先生入口: [/login/teacher](http://localhost:3000/login/teacher)
- 管理者入口: [/login/admin](http://localhost:3000/login/admin)

## 確認の流れ

1. 生徒入口で `2A-01` と入り、「二次関数の最大値がわかりません」と質問する
2. AIの整理結果と、田中先生・鈴木先生の候補を確認して投稿する
3. 先生入口で `T-1001` と入り、受付状況を切り替えて回答する
4. 管理者入口で質問の科目・分野・時間帯を見る

## 技術

- Next.js 14（App Router）と TypeScript
- ファイル保存の JSON ストア（`data/store.json`。初回起動時に確認用データを作成）
- 科目分類は校内で動くルールベースの整理器（APIキー不要）
- 認証は署名付き Cookie。入口ごとに役割を検査する
