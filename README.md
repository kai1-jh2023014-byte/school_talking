# つなぐ

高校生テックコンテスト2026 企画の実装です。

生徒が「質問したい」と思った瞬間に、対応できる先生へつなぐ学校内プラットフォームです。

> 先生を探すのではなく、質問が先生を見つける。

AIは答えを書きません。科目・分野・緊急度を整理し、いま対応できる先生へ渡すために使います。

## できること

- **生徒**: 学籍番号で入る。文章・写真・補足で質問する。整理結果と先生候補を確認して届ける。状態と回答をホームと詳細で見る
- **先生**: 職員番号で入る。「今質問OK / 少し待てば / 対応不可 / 本日終了」を出す。新しい質問・対応中・保留・転送を分けて見る。引き受ける・保留・回答・理由つき転送・終了ができる
- **管理者**: つまずき分野、科目、時間帯、状態を見る。名簿の追加・修正・無効化。学校全体の質問履歴

生徒用と先生用のログインは分かれています。学籍番号では先生画面に入れず、職員番号では生徒画面に入れません。無効にしたアカウントはログインできません。

## 質問の流れ

`投稿 → 整理 → マッチ → 受付 / 保留 → 回答 / 転送 → 終了`

対応できる先生がいるときは受付済みとして届きます。いないときは待ち行列に入ります。転送には理由が必要です。すでに回答がある質問には、二度目の回答はできません。

マッチは、受付状況 → いま抱えている未処理件数 → 担当科目・専門、の順で並べます。

質問の整理はサーバ側だけで行います。`TYPESAFE_API_KEY` があるときは TypeSafe の Jev（`POST /v1/systemone`）が科目・分野・緊急度だけを判断し、既存の教師マッチングに渡します。確信度が低いとき、Jev が失敗したとき、キーが無いときは、これまでどおり校内ルールで整理します。Jev に名簿・認証・待ち行列は渡しません。

## 起動

```bash
npm install
cp .env.example .env.local   # 任意
npm test
npm run typecheck
npm run lint
npm run build
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

- 生徒入口: [/login/student](http://localhost:3000/login/student)
- 先生入口: [/login/teacher](http://localhost:3000/login/teacher)
- 管理者入口: [/login/admin](http://localhost:3000/login/admin)

## 環境変数

`.env.example` を見てください。

| 変数 | 必須 | 説明 |
| --- | --- | --- |
| `SESSION_SECRET` | 本番は必須 | Cookie 署名。未設定時はデモ用の値 |
| `OPENAI_API_KEY` | 任意 | Jev キーが無いときだけ分類に使います。失敗・タイムアウト（4秒）時はルールへ戻します |
| `OPENAI_MODEL` | 任意 | 既定は `gpt-4o-mini` |
| `TYPESAFE_API_KEY` | 任意 | TypeSafe Jev。教科・分野・緊急度の判断だけ。キーはサーバのみ。無い・失敗・低確信度のときは校内ルールへ戻します |
| `TYPESAFE_BASE_URL` | 任意 | 既定は `https://api.typesafe.ai` |
| `TYPESAFE_DEFAULT_MODEL` | 任意 | 未設定なら `GET /v1/models` で取得します |
| `TYPESAFE_TIMEOUT_MS` | 任意 | Jev の待ち上限。既定は `4000` |
| `BCRYPT_ROUNDS` | 任意 | 既定は `10`。以前の SHA-256 ハッシュはログイン時に差し替えます |

APIキーが無くても、分類・投稿・回答は動きます。

## 10分で見る流れ

1. 生徒入口で `2A-01` / `student` と入る
2. 「質問する」を開き、「二次関数の最大値がわかりません。求め方を教えてください。」と書く
3. 「先生を見つける」で、科目が数学・分野が二次関数になることを確認する（答えは出ていない）
4. 田中先生または鈴木先生を選んで届ける
5. 生徒ホームに「待ち行列」または「受け付けました」のお知らせが出る
6. 別のブラウザ（またはシークレット）で先生入口に `T-1001` / `teacher` と入る
7. 「今質問OK」にし、新しい質問から該当の質問を開く
8. 「引き受ける」のあと、短い回答を送る
9. 生徒側を更新すると、回答と「先生から回答が届きました」が見える
10. 管理者入口で `A-0001` / `admin` と入り、分析のつまずき分野と質問履歴に「二次関数」が出ることを確認する

追加確認: 先生が転送するときは理由が必須です。別の生徒番号では、この質問は開けません。

## 技術

- Next.js 14（App Router）と TypeScript、Tailwind
- 保存は `data/store.json`（プロセス内で書き込みを直列化。初回起動時に確認用データを作成）
- 分類は校内ルールが本体。Jev（TypeSafe System One）は任意。キーが無いときは OpenAI も任意。どれも答えは出さない
- 認証は HMAC 付き httpOnly Cookie。役割は Cookie に入れ、Edge の middleware で画面を分ける
- パスワードは bcrypt。以前の SHA-256 はログイン時に再ハッシュ
- 生徒・先生の画面は 15 秒ごとに更新（WebSocket は使わない）
- 先生が一覧で見られるのは、自分の受付・担当科目の未割り当て・自分が関わった履歴だけ

この JSON ストアは、1台での校内デモ向けです。複数サーバや本格的な同時書き込みには向いていません。

## プライバシー

- 生徒は自分の質問だけ見られます
- 先生は担当外・無関係の質問を ID 指定でも開けません
- 先生一覧から学籍番号・職員番号・パスワードは返しません
- 管理者だけが名簿と全体分析を見られます
