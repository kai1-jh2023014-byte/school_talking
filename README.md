# つなぐ

高校生テックコンテスト2026 企画の実装です。

生徒が「質問したい」と思った瞬間に、対応できる先生へつなぐ学校内プラットフォームです。

> 先生を探すのではなく、質問が先生を見つける。

## できること

- **生徒**: 文章や写真で質問する。AIが科目・分野・緊急度を整理し、今対応できる先生を案内する
- **先生**: 「今質問OK / 少し待てば / 対応不可 / 本日終了」を出す。待ち行列の質問に、対応・保留・転送・回答できる
- **管理者**: 科目別・分野別・時間帯別の質問から、生徒がどこでつまずいているかを見る

AIは答えを書きません。人と人のあいだの壁を外すために使います。

## 起動

```bash
npm install
npm test
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

## デモの流れ

1. `hanako` でログインし、「二次関数の最大値がわかりません」と質問する
2. AIの整理結果と、田中先生・鈴木先生の候補を確認して投稿する
3. `tanaka` でログインし、受付状況を切り替えて回答する
4. `admin` でログインし、科目・分野・時間帯の集中を見る

## 技術

- Next.js 14（App Router）と TypeScript
- ファイル保存の JSON ストア（`data/store.json`。初回起動時にデモデータを作成）
- 科目分類は校内で動くルールベースの整理器（APIキー不要）
- 認証は署名付き Cookie
